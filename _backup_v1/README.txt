ESA ARCADE — V1
================

TODAY'S ROSTER
- Zima
- Shaza

GAMES
1) Bomb Pass
   Zima: WASD
   Shaza: Arrow Keys
   Touch the other player to pass the bomb. First to 3 round wins.

2) Coin Rush
   Zima: WASD
   Shaza: Arrow Keys
   45 seconds. Normal coin = 1, gold coin = 3.

3) Bonk Booth
   Zima: A S D
   Shaza: J K L
   Hit the key matching the hole. Bomb target = -1. 30 seconds.

HOW TO RUN
1. Open the ESA_Arcade_v1 folder.
2. Double-click index.html.
3. It should run directly in Chrome / Edge without installing anything.

HOW TO HOST
Upload the entire folder to GitHub Pages, Netlify, or another static host.
Keep the folder structure unchanged so the character images load.

FUTURE CHARACTERS
The roster is data-driven inside game.js. Add another character object and matching
normal/hurt image assets, then later add a character-select screen without rewriting
all three games.
